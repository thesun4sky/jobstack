# 면접 진행 대본
mock-interview 스킬 SKILL.md Phase 2에서, 첫 질문을 출제하기 직전 Read 한다.

**각 질문의 흐름:**

```
[면접관 어투로 질문]
────────────────────

[Q{n}/{total} - {질문유형}]

{면접관 페르소나에 맞는 어투로 질문}

(1-2분 정도로 답변해 주세요.)
```

사용자의 자유서술 답변을 기다립니다. (면접 답변은 서술형이므로 AskUserQuestion 버튼으로 받지 않습니다.)

**답변 받은 후 즉시 피드백:**

```
────────────────────
[코치 피드백]

점수 (0-100): 직무전문성 {n} | 문제해결 {n} | 의사소통 {n} | 논리구조화 {n} | 자신감·태도 {n} | 성장가능성 {n}
채점 근거: 각 축 점수마다 그 점수의 근거가 된 사용자 답변 문장을 반드시 인용합니다. (근거 없는 유사 정밀 점수 금지)

잘한 점:
- {사용자 답변에서 구체적으로 잘한 부분 인용}

개선점:
- {부족한 부분 + 구체적 대안 제시}

모범답안 힌트:
- "{이런 방향으로 답변하면 더 강해집니다}" (전체 모범답안은 아님, 방향만)

꼬리질문 예고:
- "실제 면접에서는 여기서 아래 '공통 꼬리질문 5세트' 중 하나가 이어집니다. (예: '결과를 어떻게 확인했나요?', '다시 한다면 무엇을 바꾸겠어요?')"
────────────────────
```

피드백 후 바로 다음 질문으로 넘어갑니다.

**공통 꼬리질문 5세트:**

| # | 꼬리질문 | 검증 의도 |
|---|----------|-----------|
| 1 | 어떤 문제였나요? | 문제 정의의 구체성 |
| 2 | 왜 그 방법을 택했나요? | 의사결정 근거 |
| 3 | 본인의 역할 범위는 어디까지였나요? | 기여도·팀 성과 분리 |
| 4 | 결과를 어떻게 확인했나요? | 성과의 검증·수치 |
| 5 | 다시 한다면 무엇을 바꾸겠어요? | 회고·성장 가능성 |
