# 제도·지원금 체크리스트 — 실행 시 확인

tracker(탈락 후 안내)·salary(협상 근거)·strategy(로드맵 재료)가 Read 한다. **항목의 수치·시행 여부·자격 요건은 시점에 따라 바뀌므로 이 문서에 적지 않는다.** 실행 시 WebSearch로 공식 출처(work24.go.kr, moel.go.kr, 해당 지자체·기관 공고)를 확인해 각 항목에 출처 URL과 기준일을 병기하고, 확인하지 못한 항목은 "(확인 필요)" 로 남긴다(가드레일 §3·§5).

## 탈락 후 권리 (tracker — `rejected` 갱신 직후 1회 안내)

| 항목 | 확인할 것 | 안내 방식 |
|---|---|---|
| 채용서류 반환 청구 | 채용절차의 공정화에 관한 법률의 반환 청구 요건·기한·대상 기업 규모 | 요건에 해당하면 청구 방법을 한 줄로 |
| 개인정보 파기 요청 | 지원 시 동의한 보유 기간, 파기 요청 경로 | 기업 채용 페이지의 개인정보 처리방침 확인 |
| 불합격 사유·피드백 문의 | 기업 정책(의무 아님) | 정중한 문의 문구 예시 1개 |
| 면접비·교통비 | 공고에 명시된 경우만 | 공고 문구 확인 |

## 지원 시 정책 인센티브 (salary·strategy)

| 항목 | 확인할 것 | 쓰임 |
|---|---|---|
| 비수도권 취업 청년 직접 지원 | 대상 지역·연령·고용 형태·신청 기한 | strategy 로드맵의 지역 선택 근거 |
| 구직촉진수당·국민취업지원제도 | 유형(Ⅰ/Ⅱ)·소득·재산 요건·지급 기간 | 준비 기간 생계 계획 |
| 국민내일배움카드·KDT | 훈련 과정·자부담·기간 | 역량 갭 메우기 |
| 주 4.5일제 도입 기업 | 기업 공고·정책 지원 사업 참여 여부 | salary 오퍼 비교 항목(근로시간) |
| 채용절차법 임금 명시 의무 개정 | 시행 여부·적용 범위 | 공고에 임금 범위가 없을 때 질문 근거 |
| 기업 대상 청년 고용 장려금 | 기업이 받는 지원(협상 근거로만, 금액 단정 금지) | salary 협상 시 "기업 부담 완화" 논리 |

## 갱신 주기

- 분기 1회 재확인한다(알림 자동화는 후속 과제 — `bin/jobstack-cron` 에는 아직 분기 알림이 없다).
- 이 문서에 항목을 추가할 때도 수치는 넣지 않는다(`test/lint-conventions.sh` 시장 수치 검사 대상).
