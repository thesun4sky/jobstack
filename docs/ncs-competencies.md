# NCS 직업기초능력 → 직업공통능력 체계 참조 (U-17)

ncs·cover-letter(공기업 소절)·mock-interview가 공유하는 능력 체계 참조(resume의 블라인드 체크는 `korean-format.md` 고유 규칙이라 이 파일을 쓰지 않는다). 스킬 본문에 영역 목록을 하드코딩하지 않고 이 파일을 Read 한다.

> **확인 상태**: 구 체계(10영역·34하위)는 한국산업인력공단 NCS 표준(ncs.go.kr) 기준의 확정 내용이다. 신 체계(직업공통능력 7영역·21하위)는 2026-04-28 보도(고용노동부·한국산업인력공단 발표)를 검색 요약으로 확인한 `[2차]` 근거이며, **하위능력 21개의 정확한 명칭과 기관별 필기·서류 반영 시점은 실행 시 ncs.go.kr 원문에서 확인**한다(가드레일 §3·§5). 이 파일의 신 체계 하위능력 열은 보도에 언급된 항목만 적고 나머지는 `[원문 확인 필요]` 로 둔다.

## 어느 체계를 쓸지 판정하는 규칙

1. 지원 공고·기관 채용 안내에 "직업공통능력" 또는 "AI 활용능력"이 보이면 **신 체계**로 매핑한다.
2. 공고가 "직업기초능력 10개 영역"을 그대로 쓰거나 2026-04 이전 출제 안내를 참조하면 **구 체계**로 매핑한다.
3. 판단이 안 되면 WebSearch(`"{기관명} 직업기초능력" OR "직업공통능력" 2026`)로 확인하고, 그래도 불명확하면 **두 체계 병기**로 산출하되 "기관 확인 필요"를 표시한다.
4. 산출물에는 사용한 체계와 근거(공고 문구 또는 URL·기준일)를 적는다.

| 영역 | 하위능력 |
|---|---|
| 의사소통능력 | 문서이해, 문서작성, 경청, 의사표현, 기초외국어 |
| 수리능력 | 기초연산, 기초통계, 도표분석, 도표작성 |
| 문제해결능력 | 사고력, 문제처리 |
| 자기개발능력 | 자아인식, 자기관리, 경력개발 |
| 자원관리능력 | 시간관리, 예산관리, 물적자원관리, 인적자원관리 |
| 대인관계능력 | 팀워크, 리더십, 갈등관리, 협상, 고객서비스 |
| 정보능력 | 컴퓨터활용, 정보처리 |
| 기술능력 | 기술이해, 기술선택, 기술적용 |
| 조직이해능력 | 국제감각, 조직체제이해, 경영이해, 업무이해 |

## 신 체계 — 직업공통능력 7영역·21하위 `[2차]`

| 영역 | 보도에서 확인된 하위·신설 항목 | 비고 |
|---|---|---|
| 의사소통 | [원문 확인 필요] | 구 의사소통능력 계승 |
| 수리 | [원문 확인 필요] | 구 수리능력 계승 |
| 문제해결 | [원문 확인 필요] | 구 문제해결능력 계승 |
| 자기관리 | [원문 확인 필요] | 구 자기개발·자원관리 일부 통합 추정 `[추론]` |
| 대인관계 | [원문 확인 필요] | 구 대인관계능력 계승 |
| 디지털 | **AI 활용능력**(신설), **디지털책임의식**(신설), 구 정보능력 계승 항목 | 신설 항목은 보도 확인 |
| 직업윤리 | 구 근로·공동체윤리 + **산업안전보건의식**(신설) | 신설 항목은 보도 확인 |

- 저활용 항목 폐지로 34 → 21로 줄었다는 것이 보도 요지다. 어떤 하위능력이 폐지·통합됐는지는 원문 확인 전까지 단정하지 않는다.

## 구→신 매핑 원칙 (경험→역량 변환에 쓸 때)

| 사용자 경험 유형 | 구 체계 | 신 체계 후보 |
|---|---|---|
| 생성형 AI·자동화 도구로 업무 개선 | 정보능력(컴퓨터활용·정보처리), 기술능력 | 디지털(AI 활용능력) |
| 개인정보·저작권·AI 결과 검증 경험 | 직업윤리, 정보능력 | 디지털(디지털책임의식) |
| 현장 안전·사고 예방 경험 | 직업윤리(공동체윤리) | 직업윤리(산업안전보건의식) |
| 팀 프로젝트·갈등 조율 | 대인관계능력 | 대인관계 |
| 데이터 분석·수치 보고 | 수리능력, 정보능력 | 수리, 디지털 |
| 일정·예산·역할 관리 | 자원관리능력 | 자기관리 `[추론]` |

경험을 매핑할 때는 능력 명칭을 나열하지 말고 **문제·역할·행동·결과 4분리와 수치**로 수행 근거를 쓴다(`experience-methods.md` §1·§3).
