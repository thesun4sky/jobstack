# NCS 직업기초능력 → 직업공통능력 체계 참조 (U-17)

ncs·cover-letter(공기업 소절)·mock-interview가 공유하는 능력 체계 참조(resume의 블라인드 체크는 `korean-format.md` 고유 규칙이라 이 파일을 쓰지 않는다). 스킬 본문에 영역 목록을 하드코딩하지 않고 이 파일을 Read 한다.

> **확인 상태**: 구 체계(10영역·34하위)는 한국산업인력공단 NCS 표준(ncs.go.kr) 기준이다. 신 체계(직업공통능력 7영역·21하위)는 **고용노동부 보도자료(2026-04-28) 붙임1 원문에서 2026-11-10 에 확인**했다. 기관별 필기·서류 반영 시점은 보도자료에 없으므로 **지원 기관의 공고가 기준**이며, 실행 시 공고에서 확인한다(가드레일 §3·§5).

## 어느 체계를 쓸지 판정하는 규칙

1. 지원 공고·기관 채용 안내에 "직업공통능력" 또는 "AI 활용능력"이 보이면 **신 체계**로 매핑한다.
2. 공고가 "직업기초능력 10개 영역"을 그대로 쓰거나 구 체계에만 있는 영역명(자원관리·정보·기술·조직이해능력)을 과목으로 적었으면 **구 체계**로 매핑한다.
3. 판단이 안 되면 WebSearch(`"{기관명} 직업기초능력" OR "직업공통능력" {공고 연도}`)로 확인하고, 그래도 불명확하면 **두 체계 병기**로 산출하되 "기관 확인 필요"를 표시한다.
4. 산출물에는 사용한 체계와 근거(공고 문구 또는 URL·기준일)를 적는다.

## 구 체계 — 직업기초능력 10영역·34하위 (확정)

| 영역 | 하위능력 |
|---|---|
| 의사소통능력 | 문서이해, 문서작성, 경청, 의사표현, 기초외국어 |
| 수리능력 | 기초연산, 기초통계, 도표분석, 도표작성 |
| 문제해결능력 | 사고력, 문제처리 |
| 자기개발능력 | 자아인식, 자기관리, 경력개발 |
| 자원관리능력 | 시간관리, 예산관리, 물적자원관리, 인적자원관리 |
| 대인관계능력 | 팀워크, 리더십, 갈등관리, 협상, 고객서비스 |
| 정보능력 | 컴퓨터활용, 정보처리 |
| 기술능력 | 기술이해, 기술선택, 기술적용 |
| 조직이해능력 | 국제감각, 조직체제이해, 경영이해, 업무이해 |
| 직업윤리 | 근로윤리, 공동체윤리 |

## 신 체계 — 직업공통능력 7영역·21하위 (확정)

| 영역 | 하위능력 | 구 체계와의 관계 |
|---|---|---|
| 의사소통능력 | 문서소통능력, 구두소통능력, 외국어소통능력 | 구 의사소통능력 5개 → 3개 |
| 수리능력 | 연산능력, 통계활용능력, 도표활용능력 | 구 수리능력 4개 → 3개 |
| 문제해결능력 | 문제분석능력, 대안발굴능력, 의사결정능력 | 구 사고력·문제처리 → 3개로 재편 |
| 자기관리능력 | 경력개발능력, 적응학습능력, 시간관리능력 | 영역 신설. 구 자기개발능력의 경력개발, 구 자원관리능력의 시간관리와 이름이 이어진다 |
| 대인관계능력 | 협업능력, 리더십, 갈등관리능력 | 구 대인관계능력 5개 → 3개(협상·고객서비스 명칭 없음) |
| 디지털능력 | 디지털활용능력, **인공지능(AI)활용능력**, **디지털책임의식** | 영역 신설. 구 정보능력·기술능력 영역명은 없어졌다 |
| 직업윤리 | 근로윤리, 직장공동체의식, **산업안전보건의식** | 구 공동체윤리 → 직장공동체의식, 산업안전보건의식 신설 |

- 굵게 표시한 3개는 보도자료가 "신설"로 명시한 항목이다.
- 구 체계의 **자원관리능력·정보능력·기술능력·조직이해능력·자기개발능력**은 신 체계에 영역명으로 남아 있지 않다. 보도자료는 "활용도가 낮아진 항목은 폐지"라고만 밝히고 구→신 대응표는 싣지 않았으므로, "구 체계와의 관계" 열은 두 표의 이름을 비교한 것이지 공식 대응이 아니다.

## 구→신 매핑 원칙 (경험→역량 변환에 쓸 때)

| 사용자 경험 유형 | 구 체계 | 신 체계 |
|---|---|---|
| 생성형 AI·자동화 도구로 업무 개선 | 정보능력(컴퓨터활용·정보처리), 기술능력 | 디지털능력(인공지능(AI)활용능력) |
| 개인정보·저작권·AI 결과 검증 경험 | 직업윤리, 정보능력 | 디지털능력(디지털책임의식) |
| 현장 안전·사고 예방 경험 | 직업윤리(공동체윤리) | 직업윤리(산업안전보건의식) |
| 팀 프로젝트·갈등 조율 | 대인관계능력(팀워크·갈등관리) | 대인관계능력(협업능력·갈등관리능력) |
| 데이터 분석·수치 보고 | 수리능력, 정보능력 | 수리능력(통계활용·도표활용), 디지털능력(디지털활용능력) |
| 일정 관리·마감 준수 | 자원관리능력(시간관리) | 자기관리능력(시간관리능력) |
| 새 업무·도구를 익혀 적응한 경험 | 자기개발능력 | 자기관리능력(적응학습능력) |
| 예산·물적·인적 자원 관리 | 자원관리능력 | 신 체계에 대응 하위능력 없음 — 문제해결능력(의사결정능력) 등 문항이 요구하는 능력에 맞춰 쓴다 |

경험을 매핑할 때는 능력 명칭을 나열하지 말고 **문제·역할·행동·결과 4분리와 수치**로 수행 근거를 쓴다(`experience-methods.md` §1·§3).
