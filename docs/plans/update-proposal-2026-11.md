## 0. 결이요 요약

**결(론)** — jobstack 의 방법론과 가드레일은 여전히 유효하고, "시장 수치는 실행 시 검색" 원칙 덕에 낡은 숫자는 거의 없다. 낡은 것은 숫자가 아니라 **전제**다. 지금 스킬은 "자소서를 잘 쓰면 서류를 통과한다"는 흐름을 중심에 두는데, 2026년 하반기 시장은 자소서를 줄이거나 없애고 **AI 활용 경험 서술 + 과정을 검증하는 면접**으로 옮겨 가고 있다. 다음 버전의 중심은 신기능이 아니라 이 전제 이동을 16개 스킬에 일관되게 반영하는 일이다.

**이(유)** — 확인한 것 네 가지.

1. **전형의 무게중심이 바뀌었다.** 구직자의 자소서 AI 사용 경험이 93%(캐치 1,008명, 2026-09) `[교차]`, SK하이닉스·신한은행·포스코가 자소서를 경험기술서·영상 인터뷰·활동 기술로 대체 `[교차]`, 면접장에서 LLM 으로 과제를 풀고 발표하는 형식이 등장했다 `[검색]`. 그런데 jobstack 에서 공고의 AI 사용 정책을 확인하는 단계는 코딩테스트·과제 한정이고(`company-research/references/sources.md:22`), 서류 작성 스킬 6개에는 없다 `[사실]`.
2. **참조 자료가 반년째 미확정이었다.** `docs/ncs-competencies.md` 의 신 체계 표는 하위능력 21개 대부분이 `[원문 확인 필요]` 였고, 이 파일은 ncs·cover-letter·mock-interview 3개 스킬에 복제된다 `[사실]`. 작성 당시 검색 요약은 7영역을 `경력개발`·`협업` 으로 소개해 영역명 오류를 의심했지만, **원문 대조 결과 저장소의 영역명이 맞고 검색 요약이 틀렸다**(§2-5, §9). 검색 요약만으로 스킬을 고치지 않는다는 원칙이 실제로 오류를 막은 사례다.
3. **연도가 박힌 검색어와 단정 서술이 7주 뒤 낡는다.** `job-search/SKILL.md:227-228`, `job-search/references/fetch-flow.md:28`, `cover-letter/references/keyword-checklist.md:9` 가 `2026` 을 고정한다 `[사실]`. strategy 는 이미 연도를 동적으로 치환한다.
4. **배포 경로 두 곳이 막혀 있을 가능성이 높다.** `claude plugin validate . --strict` 가 실패한다 `[실측]`. claude.ai 업로드는 프론트매터 6개 키만 허용하는데 `bin/package-skill.sh:64` 는 SKILL.md 를 그대로 복사한다 `[사실]`(업로드 실측은 못 했다).

**요(청)** — 세 단계를 제안한다.

| 단계 | 내용 | 공수 |
|---|---|---|
| **v1.1.1 정합 패치** | 참조 자료 확정(완료)·연도 고정·끊긴 참조·배포 결함 (N-01 ~ N-07) | 1~2일 |
| **v1.2.0 AI 전형 정합** | 공고 AI 정책 게이트, `ai_usage` 확장, 면접 모드 개편, 인간화 점검 개편, 전략·연봉·기업분석의 시장 정합 (N-10 ~ N-23) | 2~3주 |
| **v1.3.0 이후** | tracker 스키마, 수집 커버리지, 스카우트 프로필, 세그먼트 트랙, eval·플러그인 기반 (N-24 ~ N-38) | 3~4주 |

오너 결정은 §8 의 6건이다. 결정 1(원문 대조)·2(법정 요율)는 2026-11-10 에 확정돼 반영했고(§9), 남은 것은 3~6 이다.

| 단계 | 한 일 |

| ④ 더블체크 | 리뷰 지적 중 제안의 근거가 되는 것 20여 건을 grep·sed 로 재확인, `claude plugin validate` 재실행, 핵심 시장 사실 8건을 별도 검색으로 교차 확인 |

**더블체크에서 바뀐 것**
- 검색 요약에서 NCS 신 체계 영역명이 저장소와 다르게 나와 불일치를 의심했다. 이후 원문 대조에서 **저장소가 맞고 검색 요약이 틀린 것**으로 확인됐다(§2-5).
- `validate --strict` 실패 원인은 경고 2건이다: 루트 `CLAUDE.md` 가 플러그인 컨텍스트로 로드되지 않는다는 경고와 아이콘 없음 `[실측]`.
- strategy 는 `policy-checklist.md` 복제본을 갖고 있지만 본문에서 Read 하지 않는다(`strategy/SKILL.md:206` 은 인라인 안내뿐) `[사실]`.
- 크레딧잡의 서비스 상태는 검색으로 확인하지 못했다 `[미확인]`. "종료됐다"고 쓰지 않는다.
- 통합 테스트는 클린 클론에서 87/93, `bin` 에서 `npm install` 뒤 93/93 이다 `[실측]`. 실패 6건은 의존성 부재이며 CI 는 영향이 없다.

## 6. 기각·보류 (사유 보존)

**과거 기각 유지**
- 자동 지원·자동 제출, 합격 확률·연봉 예측 점수, Agent SDK 앱 재작성, tracker/ncs 봇 복귀, 0~100 종합 점수, 그룹별 전형표 하드코딩.
- 신규 스킬(assessment-prep·ai-assessment·coding-test·offer-compare 등). 이번에도 **신규 스킬은 제안하지 않는다.** AI 역량검사·협업 과제·처우 협의는 mock-interview 모드와 salary 절로 받는다(N-12·N-22).

**이번에 새로 기각**
- **AI 탐지 회피 기능**(탐지 점수를 낮추는 문장 변형). 오탐 사례가 있어도 방향은 고유 사실 강화와 이력 보존이다. 가드레일 §6 과 humanize-check 의 "탐지 안전 약속 금지"와 충돌한다.
- **비공식 MCP·스크래핑 확대**(링크드인·원티드). 공식 서버가 없고 계정 제한 사례가 보고됐다. 공식 API 우선 원칙을 유지한다.
- **시장 수치를 스킬 본문에 반영.** §2 의 수치는 이 문서에만 남긴다.
- **공무원 시험 대비.** 2027년 과목 개편이 있지만 jobstack 은 기업·공공기관 채용이 대상이다. 필기시험 대비는 ncs 도 범위 밖으로 둔다.

**보류**
- 원격 MCP 서버로 Cowork 에서 상태 저장. 서버 운영과 개인정보 판단이 먼저다.
- 리뷰 다관점 렌즈(인사·현업·AI 스크리닝). N-10·N-13·N-14 반영 뒤 필요성을 다시 본다.
- 플랫폼 내장 AI(사람인·잡코리아·원티드 코칭)와의 연계 안내. 기능이 빠르게 바뀌어 문서화 비용이 크다.
