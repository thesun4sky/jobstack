### 실측 근거

- `!` 동적 주입이 `~/.claude/skills/` 심링크·복사 설치 모두에서 실행되고 `${CLAUDE_SKILL_DIR}`가 명령 안에서 치환됨을 nested `claude -p`로 확인(마커 출력 요청은 모델이 프롬프트 인젝션으로 거절할 수 있어, 검증 프롬프트는 정상 과업처럼 써야 한다).
- Read 도구는 심링크 `..` 경로를 열지 못하고 Bash는 여는 것을 재확인 → 규칙 "참조는 스킬 안쪽만".
