# NCS 직업기초능력 → 직업공통능력 체계 참조 (U-17)

ncs·cover-letter(공기업 소절)·mock-interview가 공유하는 능력 체계 참조(resume의 블라인드 체크는 `korean-format.md` 고유 규칙이라 이 파일을 쓰지 않는다). 스킬 본문에 영역 목록을 하드코딩하지 않고 이 파일을 Read 한다.

> **확인 상태**: 구 체계(10영역·34하위)는 한국산업인력공단 NCS 표준(ncs.go.kr) 기준이다. 신 체계(직업공통능력 7영역·21하위)는 **고용노동부 보도자료(2026-04-28) 붙임1 원문에서 2026-11-10 에 확인**했다. 기관별 필기·서류 반영 시점은 보도자료에 없으므로 **지원 기관의 공고가 기준**이며, 실행 시 공고에서 확인한다(가드레일 §3·§5).

## 어느 체계를 쓸지 판정하는 규칙

1. 지원 공고·기관 채용 안내에 "직업공통능력" 또는 "AI 활용능력"이 보이면 **신 체계**로 매핑한다.
2. 공고가 "직업기초능력 10개 영역"을 그대로 쓰거나 구 체계에만 있는 영역명(자기개발·자원관리·정보·기술·조직이해능력)을 과목으로 적었으면 **구 체계**로 매핑한다.
3. 판단이 안 되면 WebSearch(`"{기관명} 직업기초능력" OR "직업공통능력" {공고 연도}`)로 확인하고, 그래도 불명확하면 **두 체계 병기**로 산출하되 "기관 확인 필요"를 표시한다.
4. 산출물에는 사용한 체계와 근거(공고 문구 또는 URL·기준일)를 적는다.

## 구 체계 — 직업기초능력 10영역·34하위 (확정)

| 영역 | 하위능력 |
|---|---|
| 의사소통능력 | 문서이해, 문서작성, 경청, 의사표현, 기초외국어 |
| 수리능력 | 기초연산, 기초통계, 도표분석, 도표작성 |
| 문제해결능력 | 사고력, 문제처리 |
| 자기개발능력 | 자아인식, 자기관리, 경력개발 |
| 자원관리능력 | 시간관리, 예산관리, 물적자원관리, 인적자원관리 |
| 대인관계능력 | 팀워크, 리더십, 갈등관리, 협상, 고객서비스 |
| 정보능력 | 컴퓨터활용, 정보처리 |
| 기술능력 | 기술이해, 기술선택, 기술적용 |
| 조직이해능력 | 국제감각, 조직체제이해, 경영이해, 업무이해 |
| 직업윤리 | 근로윤리, 공동체윤리 |

## 신 체계 — 직업공통능력 7영역·21하위 (보도자료 기준)

영역·하위능력 명칭은 보도자료 붙임1 표, "구 체계와의 관계" 열은 **붙임2 그림(구→신 대응도)** 을 옮긴 것이다. 붙임2 의 제목은 "개편(안)"이다.

| 영역 | 하위능력 | 구 체계와의 관계 (붙임2) |
|---|---|---|
| 의사소통능력 | 문서소통능력, 구두소통능력, 외국어소통능력 | 문서이해·문서작성 → 문서소통 / 의사표현·경청 → 구두소통 / 기초외국어 → 외국어소통 |
| 수리능력 | 연산능력, 통계활용능력, 도표활용능력 | 기초연산 → 연산 / 기초통계 → 통계활용 / 도표분석·도표작성 → 도표활용 |
| 문제해결능력 | 문제분석능력, 대안발굴능력, **의사결정능력** | 사고력·문제처리 → 문제분석·대안발굴. 의사결정능력은 신설 |
| 자기관리능력 | 경력개발능력, **적응학습능력**, 시간관리능력 | 구 자기개발능력에서 개편 — 경력개발은 유지, 자아인식·자기관리는 대응 없음. 시간관리는 구 자원관리능력에서 옮겨 옴. 적응학습능력은 신설 |
| 대인관계능력 | 협업능력, 리더십, 갈등관리능력 | 팀워크 → 협업 / 리더십·갈등관리 유지 / 협상·고객서비스는 갈등관리능력에 일부 반영 |
| 디지털능력 | 디지털활용능력, **인공지능(AI)활용능력**, **디지털책임의식** | 구 정보능력에서 개편 — 컴퓨터활용·정보처리 → 디지털활용, 정보처리의 일부가 AI활용에 반영. AI활용능력·디지털책임의식은 신설 |
| 직업윤리 | 근로윤리, 직장공동체의식, **산업안전보건의식** | 근로윤리 유지 / 공동체윤리 → 직장공동체의식. 산업안전보건의식은 신설(대응하는 구 하위능력 없음) |

- 굵게 표시한 **5개**가 붙임2 범례의 "신설능력(기존 내용 일부 반영)"이다. 보도자료 본문은 그중 3개(AI활용능력·디지털책임의식·산업안전보건의식)를 예로 들었다.
- 붙임2 에서 영역 자체가 폐지(X 표시)된 것은 **자원관리능력(시간관리 제외)·기술능력·조직이해능력**이다. 예산·물적자원·인적자원관리, 기술이해·선택·적용, 국제감각·조직체제이해·경영이해·업무이해는 신 체계에 대응 하위능력이 없다.
- 신 체계 하위능력의 **정의·평가 요소는 보도자료에 없다.** 위 대응은 명칭과 화살표 수준이며, 세부 내용은 ncs.go.kr 의 학습자료가 공개되면 그것으로 확인한다. 그림의 옅은 화살표("일부반영")는 원문 그림을 직접 확인한다.

## 구→신 매핑 원칙 (경험→역량 변환에 쓸 때)

신 체계 열은 **하위능력 명칭을 기준으로 배치한 것**이다(정의가 공개되지 않았다). 공고가 능력의 뜻을 따로 설명하면 공고 설명을 우선한다.

| 사용자 경험 유형 | 구 체계 | 신 체계 |
|---|---|---|
| 생성형 AI·자동화 도구로 업무 개선 | 정보능력(정보처리) | 디지털능력(인공지능(AI)활용능력) |
| 개인정보·저작권·AI 결과 검증 경험 | 정보능력, 직업윤리 | 디지털능력(디지털책임의식) |
| 현장 안전·사고 예방 경험 | 대응 하위능력 없음 | 직업윤리(산업안전보건의식) |
| 팀 프로젝트·갈등 조율 | 대인관계능력(팀워크·갈등관리) | 대인관계능력(협업능력·갈등관리능력) |
| 협상·고객 응대 | 대인관계능력(협상·고객서비스) | 대인관계능력(갈등관리능력 — 일부 반영) |
| 데이터 분석·수치 보고 | 수리능력, 정보능력 | 수리능력(통계활용·도표활용), 디지털능력(디지털활용능력) |
| 일정 관리·마감 준수 | 자원관리능력(시간관리) | 자기관리능력(시간관리능력) |
| 새 업무·도구를 익혀 적응한 경험 | 자기개발능력 | 자기관리능력(적응학습능력) |
| 여러 대안 중 근거를 갖고 고른 경험 | 문제해결능력(문제처리) | 문제해결능력(의사결정능력) |
| 예산·물적·인적 자원 관리 | 자원관리능력 | 대응 하위능력 없음 — 문항이 요구하는 능력(예: 의사결정능력)에 맞춰 쓴다 |
| 조직 구조·경영 이해, 업무 파악 | 조직이해능력 | 대응 하위능력 없음 — 기관 분석 근거로 지원동기·직무 이해 문항에 쓴다 |
| 기술 선택·적용 | 기술능력 | 대응 하위능력 없음 — 디지털 도구라면 디지털능력(디지털활용능력) |

경험을 매핑할 때는 능력 명칭을 나열하지 말고 **문제·역할·행동·결과 4분리와 수치**로 수행 근거를 쓴다(`experience-methods.md` §1·§3).
