# 신입 트랙 상세
resume 스킬 SKILL.md '신입 vs 경력 차별 전략' 절에서, Phase 1 모드 판단 이후 해당 트랙이 확정되면 Read 한다.

### 신입 이력서 전략

1. **학생 톤 완전 제거**: "수업에서 배웠습니다" → "프로젝트에서 직접 구현했습니다"
2. **프로젝트를 실무 관점으로 재해석**: 학교 프로젝트라도 실무 용어로 서술
   - Before: "졸업 프로젝트로 쇼핑몰을 만들었습니다"
   - After: "Spring Boot+React 기반 커머스 플랫폼 설계/개발, 결제 연동 및 재고 관리 시스템 구현"
3. **인턴/알바도 STAR로**: 단기 경험이라도 구체적 성과를 도출
4. **GitHub/포트폴리오 링크 필수**: 코드로 실력을 증명
