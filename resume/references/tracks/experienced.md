# 경력 트랙 상세
resume 스킬 SKILL.md '신입 vs 경력 차별 전략' 절에서, Phase 1 모드 판단 이후 해당 트랙이 확정되면 Read 한다.

### 경력 이력서 전략

1. **이직 사유 논리화**: 현 회사 한계 → 성장 방향 → 지원 회사 비전의 흐름
2. **레거시 기술 취급**: 과거 기술은 "경험" 수준으로만 언급, 현재 기술을 메인으로
3. **리더십 경험 부각**: 팀 리딩, 멘토링, 코드 리뷰 문화 도입 등
4. **연봉 협상 근거 내장**: 정량 성과를 연봉 협상 시 레버리지로 활용할 수 있도록 서술
5. **경력 기술서 분리**: 이력서(1~2페이지 요약) + 경력 기술서(상세 프로젝트별 서술) 분리 전략. 단 분량보다 **첫 화면 밀도가 우선**입니다.
