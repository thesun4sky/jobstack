# STAR·정량화 변환 예시
resume 스킬 SKILL.md Phase 5(STAR 적용)·Phase 6(정량화 코칭)에서 Read 한다.

#### Before→After 변환 예시

| Before (약한 서술) | After (STAR 적용) |
|-------------------|------------------|
| "웹 서비스 개발에 참여했습니다" | "레거시 모놀리식 시스템(S)의 응답 속도 개선 과제(T)에서, FastAPI 기반 마이크로서비스로 재설계(A)하여 평균 응답시간 377ms→2ms로 단축(R)" |
| "팀 프로젝트를 성공적으로 완료했습니다" | "6인 팀에서 백엔드 리드(S)로 API 설계부터 배포까지 담당(T), Docker+GitHub Actions CI/CD 구축(A)하여 배포 주기 2주→2일로 단축(R)" |
| "데이터 분석 업무를 수행했습니다" | "월 500만건 로그 데이터(S) 기반 이탈률 분석 과제(T)에서, Python+Pandas 파이프라인 구축(A)하여 분석 소요시간 9시간→70분, 89% 단축(R)" |
| "많은 고객을 관리했습니다" | "B2B 고객사 202개 중 만족도 201위(S)에서 담당자로 배정(T), 주 1회 정기 미팅+맞춤 보고서 체계 도입(A), 6개월 만에 58위로 143단계 상승(R)" |

1. **시간 절감**: "얼마나 빨라졌나요?" → 기존 시간 vs 개선 후 시간
2. **규모**: "몇 명이 사용했나요?", "몇 건 처리했나요?" → 사용자 수, 처리 건수
3. **비율 개선**: "이전 대비 몇 % 좋아졌나요?" → 효율/만족도/정확도 변화율
4. **금액**: "비용이 줄었나요? 매출이 늘었나요?" → 절감액, 매출 증가분
5. **순위/등급**: "경쟁 중 몇 등이었나요?" → 지원자 중 순위, 평가 등급

**변환 공식 템플릿:**

```
[정량화 가이드]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
"성능을 개선했습니다"
→ "응답시간 377ms → 2ms (99.5% 개선)"

"속도를 개선했습니다"
→ "처리시간 9~10시간 → 약 70분, 89% 단축"

"많은 사람을 관리했습니다"
→ "입력원 10명 x 8팀, 총 80명을 3년간 관리"

"서비스 만족도를 향상시켰습니다"
→ "202개 업체 중 만족도 201위 → 58위 (143단계 상승)"

"프로젝트를 성공적으로 완료했습니다"
→ "4개월 간 6인 팀 리드, 예정 대비 2주 조기 출시, MAU 1,200명 달성"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

#### 수치가 정말 없을 때

사용자에게 물어도 정량 지표가 나오지 않을 때, 다음 4종으로 대체합니다:

1. **범위**: "백엔드 API 12개 중 8개 담당"
2. **빈도**: "주 1회 배포"
3. **전후 비교**: 정성이라도 "수기 정리 → 양식화"
4. **담당 규모**: "고객사 15곳"
