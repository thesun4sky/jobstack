# 이력서 진단 체크리스트
resume 스킬 SKILL.md Phase 2B에서, 최초 첨삭(대조 대상 없음) 진단표를 출력하기 직전 Read 한다.

#### 7대 이력서 실수 진단

| # | 실수 | 진단 방법 | 수정 방향 |
|---|------|----------|----------|
| 1 | **희망/의지형 종결어미 남발** | "~하고 싶습니다", "~하겠습니다" 패턴 검색 | "~하고 있습니다", "~해 왔습니다"로 전환 |
| 2 | **감정/감상 과다** | "흥미를 느꼈습니다", "보람을 느꼈습니다" 검색 | 삭제하고 구체적 행동/결과로 대체 |
| 3 | **추상적 성과** | "좋은 결과", "크게 기여" 등 정량 지표 없는 서술 | before→after 수치로 변환 |
| 4 | **경험 시간순 나열** | 전체 구조가 시간순(대학→동아리→인턴→...)인지 확인 | 역량순 재배치: 가장 임팩트 있는 경험 먼저 |
| 5 | **직무 무관 소재** | 군대 극기주, 마라톤, 봉사활동 등 직무와 무관한 항목 | 삭제 또는 직무 연관성 재해석 |
| 6 | **중복 서술** | 동일한 역량/경험을 다른 표현으로 반복 | 하나로 합치고 나머지는 새로운 역량으로 채우기 |
| 7 | **기업 연구 부족** | "귀사에서 성장하고 싶습니다" 등 범용 표현 | 구체적 서비스명, 최근 행보 인용 |

진단 결과를 요약표로 출력합니다:

```
[이력서 진단 결과]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 희망/의지형 종결어미  — 3건 발견  ⚠️
2. 감정/감상 과다       — 0건      ✅
3. 추상적 성과          — 5건 발견  🔴
4. 시간순 나열          — 해당     ⚠️
5. 직무 무관 소재       — 1건 발견  ⚠️
6. 중복 서술            — 0건      ✅
7. 기업 연구 부족       — 해당     🔴
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
종합 등급: B- (개선 필요)
  └ 산출 기준: 🔴(치명) 건수 앵커 — 0건=A / 1~2건=B+ / 3~4건=B- / 5건+=C
```
