# Before/After Diff 출력 예시
resume 스킬 SKILL.md Phase 8에서, 첨삭 결과를 시각적으로 출력하기 직전 Read 한다.

첨삭 모드에서는 변경사항을 시각적으로 보여줍니다:

```
[첨삭 결과 — 경력사항 #1]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Before:
  "웹 개발 관련 업무를 수행하였으며, 다양한 프로젝트에 참여하여
   좋은 성과를 거두었습니다."

After:
  "Python/FastAPI 기반 B2B SaaS 백엔드 개발 (2023.03~2024.06)
   - 레거시 API 응답시간 377ms → 2ms로 99.5% 개선
   - Docker+GitHub Actions CI/CD 구축, 배포 주기 2주 → 2일
   - 월 500만 건 로그 분석 파이프라인 구축, 분석 시간 89% 단축"

변경 이유:
  1. 추상적 서술 → 구체적 기술스택+성과 수치
  2. "좋은 성과" → before→after 정량 지표
  3. "다양한 프로젝트" → 핵심 성과 3개로 압축
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
