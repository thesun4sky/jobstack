# ATS 최적화 세부
resume 스킬 SKILL.md Phase 4에서, 채용공고 키워드 매칭 작업에 들어갈 때 Read 한다.

**파싱 안전 체크 (자체 파일(PDF/docx)을 직접 제출할 때에만 적용)**:

- 표·그래픽·이미지·차트는 파서가 놓치기 쉬우므로 지양합니다.
- 표준 섹션 제목(경력사항·학력 등)을 사용해 파서가 구획을 인식하게 합니다.
- "디자인 템플릿 = ATS 친화"가 아닙니다. 화려한 레이아웃은 파싱 실패 위험이 있습니다.
- **예외**: 원티드·사람인 등 플랫폼 입력 폼에 직접 기입하는 경우, 그리고 한국식 표 기반 양식으로 제출하는 경우에는 이 파싱 안전 체크가 적용되지 않습니다(플랫폼이 구조화 필드를 이미 제공).

**키워드 삽입 규칙**: 최근 NLP 기반 ATS는 keyword stuffing(키워드 몰아넣기)을 무력화합니다. 키워드는 **경험 근거 문장 안에 문맥으로 배치**하고, 한 섹션에 몰아넣지 마세요. 최신 ATS 동향 인용이 필요하면 실행 시 WebSearch로 확인하고 출처·기준일을 병기합니다.
